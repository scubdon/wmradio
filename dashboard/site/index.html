Use the data

The whole log is downloadable. It is the same file the charts on this page are built from — no sampling, no aggregation.

Download

Columns

played_at_utcTimestamp the track change was observed, UTC, second precision. ISO 8601 with an explicit Z in the CSV (2026-08-13T12:34:56Z); a UTC-aware timestamp in the Parquet.
artistArtist string exactly as the stream reported it. Not normalised or deduplicated against MusicBrainz.
songTitle as reported, including any “(Feat. …)” or remix credit.

One row per play. Song identity is the (artist, song) pair. Licensed as a plain factual record — use it for whatever you like; a link back is appreciated.

Every logger outage

Want the data? Grab the full play log — one row per play, columns played_at_utc, artist, song — as CSV or Parquet, with a data dictionary alongside. Refreshed every eight hours with the rest of the site; timestamps are UTC. More about the dataset →

Artwork via Cover Art Archive / MusicBrainz and album art from the stream's metadata. Times recorded in UTC and shown in your browser's timezone, except the day/night analysis, which uses Central time — the station's own clock.
